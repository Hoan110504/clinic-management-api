# Product Overview

This is a **Clinic Management System** (Hệ thống quản lý phòng khám nội khoa) — a full-stack web application for managing an internal medicine clinic.

## Core Functionality

- Patient registration and management
- Appointment scheduling
- Doctor examination workflow (symptoms, vitals, diagnosis, prescriptions)
- Lab test ordering and result entry
- Pharmacy / medicine inventory management
- Payment and invoicing
- Role-based dashboards and reporting

## User Roles

| Role | Vietnamese | Responsibilities |
|------|-----------|-----------------|
| `admin` | Quản trị viên | User management, reports, system oversight |
| `receptionist` | Lễ tân | Patient intake, appointments, payments |
| `doctor` | Bác sĩ | Examinations, prescriptions, lab orders |
| `pharmacist` | Dược sĩ | Dispensing, inventory, medicine management |
| `patient` | Bệnh nhân | Self-service: appointments, results, prescriptions |

## Language

The codebase is bilingual — code identifiers and comments may be in English or Vietnamese. UI text and database field names are primarily Vietnamese.
